# SMOKE-001 - Homepage Smoke Test

## Tool
Testim

## Website
https://neurokyosei.cl

## Scenario
Validate that the NeuroKyosei homepage loads correctly and that critical navigation elements are functional.

## Automated Flow
1. Open homepage
2. Validate homepage hero section visibility
3. Validate navbar visibility
4. Click Agenda
5. Validate Agenda page loaded
6. Click Inicio
7. Validate homepage loaded after navigation
8. Validate WhatsApp button visibility
9. Scroll to footer
10. Validate footer copyright visibility

## Result
PASS
