# TC-001 - Homepage Smoke Test

## Project

## Test Type
Smoke Testing

## Priority

## Objective
Verify that the homepage loads correctly and that the main navigation and critical UI components work as expected.

## Preconditions
- Internet connection available
- Website accessible
- Browser: Google Chrome

## Steps
1. Open homepage
2. Validate homepage hero section visibility
3. Validate navbar visibility
4. Click Agenda
5. Validate Agenda page loaded
6. Click Inicio
7. Validate homepage loaded after navigation
8. Validate WhatsApp button visibility
9. Scroll to footer
10. Validate footer copyright visibility

## Expected Result
The homepage and critical navigation components work correctly.
